About QuickNotes

QuickNotes is a simple note-taking tool designed to help you capture ideas the moment you have them. Whether you're jotting down a quick reminder or drafting a longer thought, QuickNotes keeps everything organized and easy to find later.

How to use QuickNotes

  1. Click on "New note" to open a blank note
  2. Type your note and it saves automatically as you go
  3. Use the search button to find any note by keyword

Features

  • Automatic saving as you type
  • Fast keyword search across all notes
  • Simple, distraction-free writing area

Keyboard shortcuts

Shortcut Action
Ctrl + N Create a new note
Ctrl + S Save the current note
Ctrl + F Search notes
